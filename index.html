What to try

At the Python prompt, once the demo has reached barebox:

strategy.transition('shell')   # or 'barebox', or 'off'
strategy.barebox.run_check('version')
strategy.shell.run_check('uname -a')

labgrid's step log — what -vv turns on for pytest:

import logging
from labgrid.logging import basicConfig, StepLogger
basicConfig(level=logging.INFO)
StepLogger.start()

The bundled suite, through labgrid's own pytest plugin:

pytest.main()
pytest.main(['-v'])            # -vv adds the step log

Edit tests/test_demo.py or pytest.ini in their tabs and run it again — leaving the tab is what saves. Edits last for the session only.

How it works

  • labgrid is unmodified, installed from a wheel built from upstream. Only five QEMUDriver methods are rebound, to talk to this page instead of to a POSIX host.
  • Pyodide is CPython compiled to WebAssembly. labgrid and pytest run there, in a worker, where they are allowed to block.
  • QEMU-WASM is QEMU built with Emscripten; it boots barebox and Linux from the guest images, in this tab.
  • xterm.js and xterm-pty are the terminal. The bridge taps the pty master — where a human sits, and labgrid is just a second human.
  • CodeFlask and Prism are the editor tabs.
